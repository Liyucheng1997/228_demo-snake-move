# 🐍 蛇类三维图鉴 · Snakes 3D

基于 **Three.js** 的交互式蛇类三维建模与行为模拟。8 种常见蛇类，每一种都有独立的体型、头型、鳞片、花纹与生活史；可以观察它们的运动、吐信、捕食、防御、晒太阳、蜕皮、冬眠与繁殖。纯前端，无需构建。

## ✨ 功能

- **精细建模**
  - 身体：沿脊柱放样的可变形管，截面为“圆背 + 扁平腹”超椭圆，可叠加兜帽、桨尾、食团鼓包、呼吸、压扁、颤抖等形变
  - 鳞片：程序生成 512×4096 全长贴图，**以单枚鳞片为单位着色**（花纹边缘沿鳞片呈锯齿状，与真蛇一致）；覆瓦背鳞（光滑 / 起棱 / 颗粒）、腹鳞、成对尾下鳞；高度图 → 法线 + 粗糙度贴图
  - 头部：上下颌分别放样，头盾 / 颗粒鳞 / 唇鳞贴图按弧长映射；虹膜贴图 + 竖直或圆形瞳孔（昼夜缩放）、眼罩鳞、鼻孔、颊窝/唇窝、牙列与毒牙（蝰蛇管牙张口时竖起）、声门
  - 分叉舌：动态网格，伸出—上下摆动—两叉张开—收回
- **运动**：蜿蜒（跟随头部轨迹）、直线（腹部蠕动波）、手风琴式（交替锚定）、侧进（水平波 + 垂直波，落地盖印足迹）、游泳（向尾部增强的行波）
- **行为**（每段都有分阶段讲解与进度条）
  - 👅 吐信子：慢动作 + 左右两叉分别采集气味粒子，送入犁鼻器（辉光提示）
  - 🍖 捕食：按物种区分——伏击咬放 + 循气味轨迹追踪（响尾蛇）、缠绕绞杀（蟒、玉米蛇）、咬住注毒（眼镜蛇、银环蛇、海蛇）、尾部诱捕（竹叶青）；从头部吞咽（下颌行走、头部撑大、食团沿体内移动），消化延时（蟒心脏/小肠增大、代谢率 ×40）
  - 🛡️ 防御：兜帽展示 / 盘圈摇响环 / 吸气嘶声 / 振尾拟态 / 张口示威 / 藏头翘尾 / 游离下潜——**镜头就是它眼中的威胁者**
  - ☀️ 晒太阳：撑开肋骨、压扁身体吸热，体温上升到最适温度
  - 🦎 蜕皮：蓝眼期 → 眼睛转清 → 摩擦吻部 → 从旧皮中爬出，留下带鳞片印痕的半透明蜕
  - ❄️ 冬眠：秋季降温 → **洞穴剖面**（冻土线、隧道、越冬洞室）→ 盘绕蛰伏、心率降到每分钟几次 → 降雪 → 春季苏醒出洞；响尾蛇与同伴群聚越冬
  - 🥚 繁殖：卵生（产卵、蟒颤抖孵卵、眼镜蛇/银环蛇护卵、幼蛇探头破壳）或胎生（胎膜中产仔、母蛇陪伴）
  - 物种特有：竹叶青上树栖枝、角响尾蛇埋沙、海蛇上浮换气
  - 🔄 自动生活：循环演示它的一生
- **观察视图**：外观 / 骨骼（逐节椎骨 + 肋骨，兜帽处肋骨外展）/ 内脏（带标签，按物种调整肺的形态）/ 🔥 红外（模拟颊窝热成像：温血的鼠发亮，蛙和鱼几乎不可见）
- **环境**：森林、沙漠（沙丘与足迹）、竹林、海底（焦散、光束、海藻、鱼群），昼夜切换；WebAudio 合成的响尾声、嘶声、心跳与环境声

## 🚀 使用

双击打开 `index.html` 即可（需要联网，Three.js 通过 unpkg CDN 加载）。若浏览器限制本地文件，也可在目录下起一个静态服务器：

```bash
python -m http.server 8765
```

然后访问 <http://localhost:8765>。可用 `?sp=python` 等参数指定初始物种（`python` `cobra` `rattlesnake` `sidewinder` `corn` `bamboo` `krait` `seasnake`）。

操作：拖拽旋转 · 滚轮缩放 · 右键平移；左侧面板切换物种、行为、运动方式与视图；“时间流速”滑块可整体放慢或加快。

## 🗂️ 代码结构

```
index.html        界面与样式；加载 Three.js 后按顺序载入 js/ 下的脚本
js/util.js        数学、噪声、折线重采样、行为协程辅助（wait / tween / all）
js/species.js     8 个物种的形态参数、花纹函数与生活史文案
js/skin.js        程序化鳞片贴图（身体 / 头部 / 虹膜 / 蜕皮）
js/snake.js       Snake 类：身体与头部几何、运动驱动器、颈尾姿态叠加、骨骼与内脏
js/prey.js        猎物：鼠、树蛙、鳗鱼
js/world.js       天空光照、四种栖息地、冬眠洞穴剖面、粒子、沙地足迹
js/behavior.js    各行为的“剧本”（生成器协程）
js/audio.js       WebAudio 合成音效
js/ui.js          面板、HUD、阶段条、字幕、信息卡
js/main.js        应用状态、相机跟随、主循环
```
